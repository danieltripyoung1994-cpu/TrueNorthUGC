# ROI Audit — TrueNorthUGC

## Date: 2026-06-05

## Current Conversion Funnel

### Landing Page
- **Hero messaging**: "Canada's Premier UGC Creator Marketplace" — good but could be sharper
- **CTAs**: "Get Started" (hero), "Browse Creators" (creators section), "View Campaigns" (campaigns section)
- **Trust signals**: Stats strip (creators, brands, campaigns), testimonials, pricing transparency
- **Missing**: Creator payout transparency, brand logos, social proof above fold, urgency

### Signup Flow
- Replit Auth — low friction but may be unfamiliar to some users
- No onboarding wizard after signup
- Creator profile creation is manual, no guided flow
- No progress indicator during profile creation

### Key Metrics (To Track)
- Landing page → Signup conversion rate
- Creator signup → Profile completion rate
- Brand signup → Campaign creation rate
- Campaign view → Application rate
- Creator profile view → Message/contact rate

## Recommendations
1. Add social proof above the fold (brand logos, creator count)
2. Add "As seen on" or partner logos
3. Add creator payout transparency
4. Add urgency messaging ("Join 500+ Canadian creators")
5. Improve CTA copy: "Get Started" → "Find Your Creator" (brands) / "Get Paid Deals" (creators)
6. Add onboarding progress bar
7. Add exit-intent modal for unregistered visitors
8. A/B test hero headlines
9. Add case studies/success stories
10. Add FAQ section with conversion-focused answers
